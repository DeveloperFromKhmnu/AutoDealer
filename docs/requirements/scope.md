# Межі проєкту AutoDealerCRM

**Версія:** 1.0  
**Дата:** 2026-11-02  
**Статус:** Актуальна

---

## 1. Призначення системи

AutoDealerCRM — це веб-інформаційна система для автодилера, що спеціалізується на закупівлі вживаних автомобілів з американських аукціонів Copart та Insurance Auto Auctions (IAAI) з подальшою доставкою та реалізацією в Україні.

Система вирішує такі задачі:
- публічна презентація каталогу доступних автомобілів для потенційних покупців;
- прийом і облік заявок на підбір автомобіля;
- внутрішній облік лотів і фінансових показників для менеджерів;
- адміністративне керування обліковими записами та ліцензуванням системи;
- демонстрація механізмів кібербезпеки (автентифікація, рольова авторизація, польове шифрування, ліцензійна перевірка, аудит-журнал).

---

## 2. Що входить до системи (In-Scope)

### 2.1. Функціональні модулі

| Модуль | Опис |
|--------|-------|
| Публічний каталог | Перегляд автомобілів з маскованим VIN-кодом та статусами |
| Модуль заявок | Форма швидкої заявки на підбір авто (для гостей) |
| Модуль лотів | Додавання та редагування лотів (для менеджерів) |
| Модуль обліку | Внутрішня собівартість, повний VIN (для менеджерів) |
| Модуль ліцензування | Завантаження та перевірка файлу `dealer.lic` (для адміна) |
| Модуль аудиту | Журнал входів і адміністративних дій (для адміна) |
| Управління акаунтами | Створення та блокування облікових записів менеджерів (для адміна) |

### 2.2. Ролі користувачів

- **Гість (Покупець)** — неавтентифікований відвідувач.
- **Менеджер** — автентифікований працівник.
- **Адміністратор** — привілейований користувач системи.

### 2.3. Безпекові механізми (In-Scope)

- Cookie-based автентифікація / ASP.NET Core Identity.
- Рольова авторизація (RBAC) з атрибутами `[Authorize(Roles = "...")]`.
- Польове шифрування конфіденційних полів бази даних (VIN, телефон, собівартість) за допомогою AES-256.
- Криптографічна перевірка файлу ліцензії (HMAC-SHA256 або RSA підпис).
- Журнал безпеки (Security Audit Log): спроби входу, дії адміністратора.
- Маскування VIN-коду в публічному каталозі.
- Захист від CSRF (AntiForgeryToken на всіх формах).

## 3. Що НЕ входить до системи (Out-of-Scope)

| Виключення | Пояснення |
|---|---|
| Інтеграція з API Copart / IAAI | Дані вводяться вручну менеджером |
| Онлайн-оплата / еквайринг | Система не обробляє фінансові транзакції |
| Поштові та SMS-сповіщення | Не реалізуються в навчальному варіанті |
| Мобільний застосунок | Лише веб-інтерфейс |
| Мультимовність (i18n) | Інтерфейс виключно українською мовою |
| Публічне хмарне розгортання | Система розгортається локально (LocalDB / SQL Express) |
| Двофакторна автентифікація (2FA) | Не входить до обсягу навчального проєкту |

## 4. Зовнішні взаємодії

```
[Браузер покупця] ──HTTP/HTTPS──> [ASP.NET Core MVC]
[Браузер менеджера] ──HTTP/HTTPS──> [ASP.NET Core MVC]
[ASP.NET Core MVC] ──EF Core──> [MS SQL Server LocalDB]
[Адмін] ──завантажує──> [файл dealer.lic]
```

Зовнішніх API-інтеграцій немає. Система є автономною.

---

## 5. Обмеження середовища

- Розгортання: локальна машина розробника (Windows 10/11).
- СУБД: Microsoft SQL Server LocalDB або SQL Server Express.
- Мережа: localhost (порт за замовчуванням Kestrel / IIS Express).
