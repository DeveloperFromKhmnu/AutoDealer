# Документація проєкту AutoDealerCRM

## Загальний опис

**AutoDealerCRM** — навчальний комерційний веб-сервіс (CRM) для автодилера, що спеціалізується на доставці вживаних автомобілів зі США з аукціонів Copart та IAAI. Система реалізована як ASP.NET Core MVC-додаток з базою даних Microsoft SQL Server та демонструє практичне застосування комплексних механізмів кібербезпеки:
- Автентифікація через ASP.NET Core Identity (PBKDF2) та захищені Cookie (ЛР №4).
- Керування доступами на основі комбінованої моделі RBAC + ABAC (ЛР №5).
- Симетричне польове шифрування конфіденційних даних через AES-256-GCM (ЛР №6).
- Контроль цілісності та автентичності через GCM Auth Tag та HMAC-SHA256 ліцензування `dealer.lic` (ЛР №7).

## Технологічний стек

- **Платформа:** .NET 8, ASP.NET Core MVC
- **База даних:** Microsoft SQL Server (LocalDB / SQL Express)
- **ORM:** Entity Framework Core 8 (Code-First)
- **Безпека:** ASP.NET Core Identity, Cookie Authentication, `System.Security.Cryptography`
- **Дослідницький модуль:** `CryptoLabsExecutor` (консольний стенд для практичних пунктів ЛР №4, 6, 7)
